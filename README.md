# Health Companion

You're building HealthGuard AI — an intelligent healthcare risk prediction system for your final-year CS project. It started out covering both diabetes and heart disease prediction, but you decided to simplify the scope to diabetes prediction only (dropping the heart disease feature), alongside the other features: secure login, patient profile, BMI calculator, blood pressure analysis, personalized recommendations, risk dashboard/graphs, and a downloadable PDF health report — built with Django (backend), React (frontend), SQLite (database), and scikit-learn (ML: Logistic Regression vs Random Forest, best one selected automatically).
